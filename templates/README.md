# App templates

| Template            | Purpose                                      |
|---------------------|----------------------------------------------|
| `workbench-app/`    | Vite + React + Tailwind + IDP workbench shell |

Generate apps from the repo root:

```bash
pnpm create-app <app-dir-name> [--product loms] [--port 5175]
```

See `docs/workbench-shell.md` for layout conventions.
